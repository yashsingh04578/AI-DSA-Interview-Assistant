\# AI DSA Interview Assistant



An AI-powered interview preparation tool built using Python and Streamlit.



\## Features



\* Generate explanations for DSA topics

\* Interview-focused learning

\* Time and Space Complexity analysis

\* Java code examples

\* Common interview questions

\* Secure API key management using environment variables



\## Tech Stack



\* Python

\* Streamlit

\* Google Gemini API

\* Git \& GitHub



\## Installation



```bash

git clone https://github.com/yashsingh04578/AI-DSA-Interview-Assistant.git

cd AI-DSA-Interview-Assistant

pip install -r requirements.txt

python -m streamlit run app.py

```
